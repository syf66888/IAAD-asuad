# Environment Configuration

The runtime configuration is Linux, NVIDIA RTX 4090, Python 3.8.20, PyTorch 1.13.1+cu116, TorchVision 0.14.1+cu116, and CUDA 11.6. Python dependencies are listed in `requirements.txt`. Java is required for caption evaluation, and FFmpeg is required for video preparation.

Follow the installation commands in the repository README.
